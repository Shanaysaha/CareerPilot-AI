# Full application source

`CareerPilot_AI_Source.zip` contains the complete tracked frontend and backend source, database migrations, starter content, tests, dependency manifests, lockfiles, and setup guides.

The editable source folders at the repository root are [frontend](../frontend/) and [backend](../backend/). Continue development there. Refresh this submission archive after changing the application by following [Support](../Support/README.md).

JavaScript library versions are recorded in each package-lock.json. Python dependencies are pinned in backend/ai-service/requirements.txt. Install them using the included instructions.
