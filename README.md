# CareerPilot AI

BCA major project for student career and placement preparation.

## Project folders

- `frontend/` — responsive web interface and installable PWA; implementation will be added later.
- `backend/` — beginner-friendly API and AI service code; keep business rules easy to explain.
- `docs/` — revised synopsis, SRS, roadmap, and project references.

## Planned backend direction

- Node.js and Express for the main REST API.
- Python and FastAPI for AI features when they are introduced.
- PostgreSQL for persistent project data.

Keep API keys and passwords in local environment files, never in Git. Use synthetic student data during development.
