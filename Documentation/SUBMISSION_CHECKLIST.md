# University submission checklist

This checklist follows the GitHub requirements in Updated Major Project Format Dec 2026 for BCA. Review it again when the report and presentation are finished.

| Required folder | Repository contents | Status |
| --- | --- | --- |
| Presentation | Existing system design PPTX, 15 slides | Final assessment presentation and embedded repository link pending |
| Documentation | Word report with cover, acknowledgment, certificate and declaration | Report chapters and final repository-link appendix pending |
| Source Code | Complete tracked application source archive with library definitions and lockfiles | Packaged |
| Program | Compiled website and backend application archive with run instructions | Packaged for local execution after runtime and database setup |
| Support | Runtime requirements, dependency instructions, packaging script and checksums | Included |
| Help | Installation and role-based user manual | Included |

Before final submission, complete the report, update the slide deck with final implementation and results, and include https://github.com/Shanaysaha/CareerPilot-AI in the report's final appendix and in the PowerPoint itself. Confirm the official project title because the current report uses Carrier Plot AI and the application uses CareerPilot AI.

The university's Program requirement uses the term executable. This repository supplies a runnable browser application bundle with its Node.js and Python services. Confirm this delivery format with the supervisor if a standalone desktop executable is required.
